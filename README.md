## Featured Projects:

**VNMS (Virtual Network Management System)** A containerized NetDevOps platform for secure, automated infrastructure management.

Project Overview: VNMS is an enterprise-grade web application that abstracts complex CLI network configurations into structured data models. It empowers network operators to safely automate VLAN provisioning, interface configurations, and device backups through a UI, executing the changes safely via a containerized Ansible backend.  

Tech Stack: Python, FastAPI, React, Docker, Ansible, Jinja2.  

AI Implementation:

    AI-Driven Development: Leveraged local AI coding agents (Cline/Ollama) for backend code optimization and generating automated API testing parameters.  
    
    Prompt Engineering: Developed documented, structured prompts to allow AI to generate perfectly formatted Ansible host_vars and Jinja templates based on natural language network requests.  
    
Future Improvements:

    Expanding the execution engine to support multi-vendor environments (e.g., Aruba, MikroTik).  
    
    Integrating an internal AI assistant to provide real-time chat-based network telemetry analysis and zero-touch provisioning.  

**Ashen Path** is a dark fantasy self-improvement and fitness tracking application that turns real-life actions into an RPG-style progression system.

The app allows users to track workouts, nutrition, quests, journal entries, weekly reviews, boss progress, world restoration, and exportable progress reports. It was built as a practical learning project to demonstrate frontend development, project planning, data modeling, local persistence, responsive design, and AI-assisted development.

### What Ashen Path Includes

- Quest completion system with XP, levels, ranks, HP, and Sanity
- Trial of Iron workout runner with set logging and rest timers
- Nutrition tracking for calories, protein, and water
- Journal entries, fantasy chronicle, daily summaries, and weekly review
- Boss damage and world restoration mechanics
- Custom quests, custom workouts, and exercise tracking
- Export for review and full backup/import workflow
- PWA/mobile-ready structure for iPhone Home Screen use
- Local-first data storage using browser storage
